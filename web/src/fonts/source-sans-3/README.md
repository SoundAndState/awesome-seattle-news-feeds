# Source Sans 3

Article attribution, dates, status, and controls. Upright variable weights from 400 to 700.

These unmodified Latin and extended Latin WOFF2 subsets were downloaded from [Google Fonts](https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400..700&display=swap) on September 15, 2026. The matching Unicode ranges are preserved in [typography.css](../../typography.css). Other characters use the system fallbacks. Vite bundles these files with the site; neither the build nor the browser contacts Google Fonts. The reader uses font-display: swap and disables synthetic styles.

Source Sans 3 uses the [SIL Open Font License 1.1](OFL.txt), separate from the catalog's CC0 license. The build includes the full license in third-party-notices.txt.
