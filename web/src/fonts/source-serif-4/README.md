# Source Serif 4

Article headlines, excerpts, and preview body text. Upright and italic variable fonts include optical sizing.

These unmodified Latin and extended Latin WOFF2 subsets were downloaded from [Google Fonts](https://fonts.googleapis.com/css2?family=Source+Serif+4:ital,opsz,wght@0,8..60,400..700;1,8..60,400..700&display=swap) on September 15, 2026. The matching Unicode ranges are preserved in [typography.css](../../typography.css). Other characters use the system fallbacks. Vite bundles these files with the site; neither the build nor the browser contacts Google Fonts. The reader uses font-display: swap and disables synthetic styles.

Source Serif 4 uses the [SIL Open Font License 1.1](OFL.txt), separate from the catalog's CC0 license. The build includes the full license in third-party-notices.txt.
